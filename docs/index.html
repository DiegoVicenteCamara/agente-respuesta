Respuesta — Agente de voz con subagentes proactivos

Llama desde tu navegador, pide una tarea compleja (investigar, resumir, comparar…) y un orquestador la descompone y delega a subagentes en segundo plano. Cuando hay avances, el agente te interrumpe por voz con la novedad, respetando los turnos de conversación.

Empezar en 4 pasos Ver código

Sin demo en vivo: la voz en tiempo real (OpenAI/LiveKit) tiene coste continuo y no se ofrece como servicio público. Puedes probarlo en local o en modo prueba sin voz.

Explicación — arquitectura

Los planos de voz (síncrono, <800 ms) y de ejecución (asíncrono) están desacoplados mediante un bus de eventos Redis, fiel a la investigación Sistemas Multiagente y Voz Interactiva. 

[Navegador (LiveKit) ⇄ WebRTC] → backend (FastAPI /token)
                                        │
                    Worker de voz LiveKit (OpenAI Realtime API)
                        ├─ tool delegate_complex_task → despacha a Celery
                        └─ listener Redis → habla proactivamente
                                        │
                              Redis (pub/sub + broker)
                                        │
         Celery worker → LangGraph (supervisor + subagentes en paralelo)
             planner → research (fan-out) → synthesize (publican eventos)

Cómo notifica

  • priority: silent → actualiza estado, no interrumpe.
  • priority: info → «Disculpa que te interrumpa…» con barge-in.
  • priority: urgent → «Necesito tu atención…».

Tutorial — quickstart en 4 pasos

  1. Alta en servicios (Fase 0): LiveKit Cloud, OpenAI, Redis local con Docker.
  2. Configura y crea el entorno: 
    cp .env.example .env
# rellena LIVEKIT_URL, LIVEKIT_API_KEY, LIVEKIT_API_SECRET, OPENAI_API_KEY
python3 -m venv .venv
.venv/bin/pip install -r backend/requirements.txt
  3. Arranca Redis, el worker Celery, el agente de voz y la web: 
    redis-server
.venv/bin/celery -A backend.orchestrator.tasks.celery_app worker -P solo -l info
.venv/bin/python -m backend.voice.agent dev
.venv/bin/uvicorn backend.api.main:app --port 7860
  4. Abre http://localhost:7860, pulsa Llamar y pide: «Investiga las últimas novedades sobre agentes de IA en español y resúmelo».

Modo prueba (sin voz, sin créditos OpenAI)

La web incluye un panel Modo prueba: escribe un objetivo, pulsa Iniciar tarea y verás los avisos (plan_ready → subtask_done → analysis_ready) por el mismo bus Redis con la misma prioridad que usaría la voz. Detrás: POST /debug/run despacha a Celery y GET /debug/stream (SSE) lo reenvía al navegador. Sin TAVILY_API_KEY se usa DuckDuckGo.

Cómo colaborar — automatización agent-ready

Los issues con la label agent-ready los implementa de forma autónoma un agente opencode y los devuelve como Pull Request listo para revisión. Detalles en la sección de automatización del README y en el ADR-003.
